DecodeLabs AI Internship Projects 

This repository contains three beginner-friendly AI and Machine Learning projects completed as part of my DecodeLabs Internship. The projects demonstrate basic concepts of Python, AI logic, machine learning, and recommendation systems.

Projects 1. Rule-Based AI Chatbot 

A simple Python chatbot that responds to predefined user inputs using if-else logic and a continuous while loop.

Key Concepts: Python, control flow, decision-making, user input.

2. Data Classification Using AI 

A basic machine learning project using the Iris dataset and Logistic Regression to classify flowers into Setosa, Versicolor, and Virginica.

Key Concepts: Dataset handling, train-test splitting, feature scaling, model training, prediction, and evaluation.

3. Recommendation System 

A simple recommendation system that takes user preferences such as category and genres, matches them with available items, calculates scores, and displays suitable recommendations.

Key Concepts: User preferences, pattern matching, scoring logic, sorting, and recommendation concepts.

Technologies Used Python Scikit-learn Machine Learning Lists & Dictionaries Functions Conditional Statements Loops Learning Outcomes 

Through these projects, I gained practical experience in Python programming, AI logic, supervised machine learning, data preprocessing, classification, and basic recommendation systems.
