Rule-Based AI Chatbot Description 

A simple rule-based chatbot developed using Python. The chatbot responds to predefined user inputs using if-else decision-making logic.

Features Handles greetings such as hello, hi, and hey Responds to basic questions Handles exit commands such as bye, exit, and quit Runs continuously using a while loop Uses basic control flow and decision-making logic How to Run 

1. Install Python 

Make sure Python is installed on your computer.

Check the installation:

python --version 

2. Open the Project Folder 

Open a terminal in the project folder containing chatbot.py.

3. Run the Chatbot python chatbot.py 

4. Start Chatting 

Example:

You: hello 
Bot: Hello! How can I help you? 
You: how are you 
Bot: I'm doing great! Thanks for asking. 
You: bye 
Bot: Goodbye! Have a great day! 

The chatbot will continue running until the user enters bye, exit, or quit.
